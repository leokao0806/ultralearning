# Ultralearning Skill Suite — Agent Instructions

When any user asks to design, structure, audit, or optimize an intensive learning project or curriculum using Scott Young's *Ultralearning* methodology, you MUST invoke the master orchestrator skill:

`skills/using-ultralearning/SKILL.md`

### Core Behavioral Mandates:
1. **The Anti-Slop Rule:** NEVER generate a superficial 1-page monolithic 12-week study plan in a single turn. Ultralearning is an active, iterative feedback loop, not a static report.
2. **Interactive Gating:** Plan only ONE sprint (2-4 weeks) at a time. Each sprint must have an unambiguous, pass/fail Gate Condition (closed-book exam or working project deliverable).
3. **Conversational Discipline:** Ask 1-2 focused questions at a time. Never overwhelm the user.
4. **The Modular Suite:** Route dynamically between:
   - `metalearning` (curriculum reverse-engineering, benchmarking, CFP decomposition)
   - `sprint-planner` (granular single-sprint scheduling)
   - `drill-coach` (struggle timer, interactive Feynman testing, deliberate drills)
   - `audit-and-pivot` (weekly calibration, rate-of-learning checks, strategic experimentation)
